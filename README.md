# 📝 OCR - Image to Text Extractor

A simple web app that extracts text from images using Optical Character Recognition (OCR), built with Python, EasyOCR, and Streamlit.

## 🎯 Features

- Upload any image (PNG, JPG, JPEG)
- Automatically detects and extracts text using a pre-trained deep learning model
- Clean, easy-to-use web interface
- Download extracted text as a `.txt` file
- Handles errors gracefully (e.g., images with no readable text)

## 🛠️ Tech Stack

- **Python** — core programming language
- **EasyOCR** — pre-trained deep learning model for text detection and recognition
- **Streamlit** — for building the web interface
- **Pillow** — image handling
